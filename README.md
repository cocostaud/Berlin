# Carnet Photo Berlin — bêta

Version bêta basée sur l’export Google Maps du 10 août 2026.

- 55 lieux Berlin (l’entrée Hambourg a été retirée)
- correction du décalage d’adresses détecté dans le CSV
- Carte Leaflet / OpenStreetMap
- géocodage progressif via Nominatim, mémorisé sur l’appareil
- onglets Catégories et Quartiers
- recherche
- photos d’illustration recherchées automatiquement sur Wikimedia Commons
- bouton « autre photo » dans la fiche pour tester un autre résultat
- liens Google Maps et Apple Plans
- PWA / GitHub Pages

## Installation GitHub Pages
Créer un dépôt `Berlin`, déposer le contenu de ce dossier à la racine puis activer GitHub Pages sur la branche `main`.

## Limite assumée de cette bêta
Les photos sont choisies automatiquement par recherche Wikimedia : certaines pourront être imparfaites. C’est volontaire pour permettre une première validation rapide avant de figer les 55 images une par une.
